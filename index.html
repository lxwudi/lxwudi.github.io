01SURBNRELIABLE SPEECH AI
Knowledge-Based Systems已发表 · 第一作者Published · First author

A Simplicity-Oriented Uncertainty-Aware Bayesian Neural Network for Reliable Speech Emotion Recognition

Lingxiao Fu, Huiyun Zhang, Gaigai Tang · 2026

融合冻结的 Whisper 语音表征与轻量贝叶斯网络，通过能量引导门控和温度校准，改善语音情感识别的预测可靠性。A compact Bayesian framework combining frozen Whisper representations, energy-guided gating, and temperature scaling for reliable speech emotion recognition.

99.07%EMODB 准确率EMODB accuracy0.1357 → 0.0348四数据集平均 ECEMean ECE across 4 datasets5.58M下游可训练参数Trainable downstream parameters
论文Paper ↗Code ↗
研究细节Research details+

融合 Log-Mel 声学特征与冻结的 Whisper large-v3 表征，通过能量引导稀疏门控（EGSG）调节特征响应。采用变分贝叶斯建模与蒙特卡洛采样估计预测分布，并以折外温度缩放校准置信度。

Log-Mel acoustic features are fused with frozen Whisper large-v3 representations. Energy-guided sparse gating (EGSG) modulates feature responses, while variational Bayesian modeling and Monte Carlo sampling estimate predictive distributions. Out-of-fold temperature scaling calibrates confidence.

在 CASIA、EMODB、IEMOCAP 和 SAVEE 上进行语句级五折交叉验证。参数量仅计入下游可训练模型，不包含冻结的 Whisper 编码器。

Evaluated with utterance-level five-fold cross-validation on CASIA, EMODB, IEMOCAP, and SAVEE. The parameter count excludes the frozen Whisper encoder.

02MarTKVLLM INFERENCE
COLING在投 · 第一作者Under review · First author

MarTKV: Efficient Speculative Decoding via Shared-State Markov Candidate Trees and Request-Local Paged Execution

将共享状态候选树与请求局部分页 KV 管理结合，在减少重复候选计算的同时，支持动态请求下的连续推理服务。Shared-state candidate trees and request-local paged KV management reduce redundant computation while supporting dynamic requests in continuous serving.

4.04–4.09×较自回归解码的平均离线加速Mean offline speedup over AR+10.61–26.37%90% 负载下的 SLA 吞吐提升SLA goodput gain at 90% load
研究细节Research details+

跨分支共享基础 logits 与逐层 Top-K 候选集，结合父节点条件评分，在全局节点预算内采用最佳优先搜索构建候选树。为目标模型与草稿模型分别设计有效 KV 保留规则，支持变长提交、请求结束和空位补入。

Base logits and depth-wise Top-K shortlists are shared across branches. Parent-conditioned scoring and budgeted best-first selection construct candidate trees. Separate KV retention rules for the target and draft models support variable-length commits, request completion, and slot refill.

结果来自四个目标模型。在线有效吞吐量的比较基线为固定块分页 DSpark；有效请求须满足所设定的时延约束。

Results are measured across four target models. Online goodput is compared with paged fixed-block DSpark and counts requests meeting the specified latency constraints.

03CoveTreeSEMANTIC OPERATORS
DASFAA在投 · 第一作者Under review · First author

CoveTree: Coverage-Tree Speculative Decoding for General-Purpose Generation and LLM Semantic Operators

在固定验证预算下，以逐层固定宽度选树保留多条候选路径，提升通用生成与逐行文本转 JSON 任务的解码效率。Fixed-width selection at each depth retains multiple candidate paths within a verification budget, accelerating general-purpose generation and row-wise text-to-JSON tasks.

2.78–3.60×较自回归解码的配对加速Paired speedup over AR3,000行文本转 JSON 测试Text rows in semantic-operator tests
研究细节Research details+

复用单次草稿骨干计算，通过父节点条件评分和累计路径分数逐层选树。使用树注意力并行验证候选路径，由目标模型采样驱动路径遍历，仅提交实际访问路径的 KV 状态，支持贪心与随机解码。

A single draft backbone pass is reused for parent-conditioned scoring and cumulative path selection. Tree attention verifies candidates in parallel, while target-driven sampling traverses paths and commits only visited KV states. The framework supports greedy and stochastic decoding.

四个目标模型、五项通用生成任务上的聚合吞吐量均为所比较方法中最高。上述 2.78–3.60× 加速对应单请求并发的语义算子测试，标签准确率与自回归解码相近。

The method attains the highest aggregate throughput among compared methods on all four models across five general-generation tasks. The reported 2.78–3.60× speedup is for semantic operators at concurrency one, with label accuracy comparable to autoregressive decoding.
